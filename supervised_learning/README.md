# Supervised Learning

Regression and classification examples using NumPy, scikit-learn, and PyTorch.

- [intro_examples.py](intro_examples.py): regression, data splitting, and classification metrics.
- [linear_regression.py](linear_regression.py) and [multiple_linear_regression.py](multiple_linear_regression.py): single-variable and multivariable regression.
- [gradient_descent.py](gradient_descent.py): fitting a linear model with gradient descent.
- [normalization.py](normalization.py): min-max scaling and standardization.
- [linear_classifier.py](linear_classifier.py), [logistic_regression.py](logistic_regression.py), and [multiclass_classification.py](multiclass_classification.py): classification methods.
