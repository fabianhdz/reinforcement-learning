# Reinforcement Learning

Reinforcement learning algorithms and machine learning examples, organized by topic. Explore tabular methods, deep RL, policy optimization, and decision transformers, along with neural networks and computer vision.

## Topics

| Topic | Examples |
| --- | --- |
| [Supervised learning](supervised_learning/) | Regression, gradient descent, normalization, and classification |
| [PyTorch fundamentals](pytorch_fundamentals/) | Tensors, data loading, model definitions, and training |
| [Neural networks](neural_networks/) | XOR, MNIST, activation functions, and dropout |
| [Convolutional neural networks](convolutional_neural_networks/) | FashionMNIST, MNIST, and convolution padding |
| [Monte Carlo](monte_carlo/) | GridWorld prediction and control |
| [Temporal-difference learning](temporal_difference/) | TD prediction, SARSA, and Q-learning |
| [Function approximation](function_approximation/) | Linear models and deep neural networks |
| [Deep Q-learning](deep_q_learning/) | CartPole DQN, rendering, and TensorBoard |
| [Policy gradients](policy_gradients/) | REINFORCE and policy-based CartPole agents |
| [Actor-critic](actor_critic/) | Actor-critic agents with GPU and TensorBoard support |
| [Proximal policy optimization](proximal_policy_optimization/) | PPO with clipped policy updates |

| [Decision transformers](decision_transformers/) | Trajectory collection, offline RL, and evaluation |
| [Image segmentation](image_segmentation/) | U-Net on Oxford-IIIT Pet |

## Running examples

Install the dependencies used by the script you want to explore, then run it from its directory. Examples use packages such as PyTorch, NumPy, Gym or Gymnasium, and Matplotlib. Dataset and checkpoint requirements are noted in the relevant folders.
